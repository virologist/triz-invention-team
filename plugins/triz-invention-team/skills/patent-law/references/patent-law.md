# 中国专利法核心法条速查

## 一、三性条款（专利法22条）

| 法条 | 要件 | 标准 |
|------|------|------|
| 22.2 | 新颖性 | 不属于现有技术；无抵触申请（他人在申请日前向专利局提交、申请日后公布的同样发明） |
| 22.3 | 创造性 | 与现有技术相比具有**突出的实质性特点**和**显著的进步**（实用新型为实质性特点和进步） |
| 22.4 | 实用性 | 能够制造或使用，能产生积极效果 |

现有技术定义：申请日（有优先权的指优先权日）以前在国内外为公众所知的技术（出版物公开/使用公开/其他方式公开）。

## 二、创造性"三步法"

1. 确定最接近的现有技术
2. 确定发明的区别特征和发明实际解决的技术问题
3. 判断要求保护的发明对本领域技术人员来说是否显而易见（现有技术整体上是否存在技术启示）

常见攻击点：
- 区别特征为惯用手段的直接置换
- 技术效果可以预期（结合启示明显）
- "事后诸葛亮"反制：效果必须源于区别特征且不可预期

## 三、客体与排除条款

| 法条 | 内容 |
|------|------|
| 2.2 | 发明=对产品、方法或其改进提出的新的技术方案 |
| 5 | 违反法律/社会公德/妨害公共利益不授权；违法获取遗传资源不授权 |
| 25 | 不授权：科学发现/智力活动规则方法/**疾病诊断治疗方法**/动植物品种/原子核变换物质/平面印刷标识设计 |

注：疾病诊断治疗方法不授权，但药物化合物/制剂/制药用途（Swiss型用途权利要求）可授权；动植物品种不授权，但生产方法可授权。

## 四、申请文件条款

| 法条 | 要求 |
|------|------|
| 26.3 | 说明书清楚完整，以所属技术领域技术人员能够实现为准（充分公开） |
| 26.4 | 权利要求书以说明书为依据，清楚、简要限定保护范围 |
| 33 | 修改不得超出原说明书和权利要求书记载的范围 |
| 31.1 | 单一性：属于一个总发明构思的两项以上发明可合案 |
| 细则20.2 | 独立权利要求应记载解决技术问题的必要技术特征 |

## 五、对比文件分级（检索报告符号）

| 符号 | 含义 | 威胁级 |
|------|------|--------|
| X | 单独影响新颖性或创造性 | 最高 |
| Y | 与其他Y组合影响创造性 | 高 |
| A | 背景技术文件 | 低 |
| R | 他人申请日前后提交的同样发明（抵触/重复授权） | 高（程序性） |
| P | 公开日介于申请日与优先权日之间 | 视情形 |
| E | 公开日在申请日之后但申请日在前的同样申请（抵触申请） | 高 |

## 六、实质审查程序要点

- 启动：申请日起3年内请求实审（法35），逾期视撤
- 审查顺序：理解发明→检索→三性+形式审查→一通→答复→继续审查/授权/驳回
- 驳回前听证原则：事实、理由、证据须先告知申请人
- 答复期限：一通通常4个月，N通2个月
- 常见结案：授权/驳回/视撤/复审

## 八、形式缺陷高频点（撰写自查）

- 从属权项未引独立权项（细则20.3）
- 多项引多项（细则22禁止）
- 权项术语与说明书不一致（细则19.3）
- 附图含文字（部分国家申请要求）
- 摘要超300字（细则23）
- 说明书引用权利要求（说明书应独立成立）
