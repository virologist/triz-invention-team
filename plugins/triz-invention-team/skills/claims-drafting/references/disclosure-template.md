# 技术交底书标准模板

> 使用者：disclosure-architect（谭无隐）。本模板参照高价值专利培育工作规范附录B设计。

## 模板正文

```
# 发明专利技术交底书

## 一、发明名称
一种____的____（产品/方法/系统）

## 二、技术领域
本发明属于____技术领域。

## 三、背景技术与现有缺陷
【2-4段】
1. 现有技术方案A如何解决该问题：____
2. 现有技术方案B如何解决该问题：____
3. 现有技术共同存在的缺陷：
   - 缺陷1（导致的技术后果）：____
   - 缺陷2（导致的技术后果）：____
【注意：不引用具体专利号，只描述技术现状】

## 四、要解决的技术问题
本发明针对____问题，提供一种____，以解决现有技术中____的技术问题。

## 五、技术方案
### 5.1 必要技术特征（独立权利要求素材）
1. 特征1：____（部件/步骤名称+构造/参数+位置/连接关系）
2. 特征2：____
3. 特征N：____
4. 特征间技术关系：____与____通过____连接/作用，从而____

### 5.2 可选技术特征（从属权利要求素材）
1. 优选1：____（附加限定+带来的增益）
2. 优选2：____

### 5.3 工作原理与过程
【产品类】整体结构→各部件协同→工作过程分步描述
【方法类】工艺流程分步骤+各步骤参数（温度/时间/浓度/压力等范围值）
【软件类】处理流程+输入输出+硬件载体

## 六、有益效果
1. 效果1（量化）：相比现有技术，效率提升____%/成本降低____%/精度提高____
2. 效果2（定性+机理）：____，其机理在于____
【每个效果须能追溯到具体技术特征】

## 七、具体实施例
### 实施例1（最优方案）
完整参数+操作步骤+结果数据

### 实施例2（变形方案，可选）
边界参数或替代结构

## 八、附图说明
图1：____（结构示意图/流程图/原理框图）
图2：____
【每图说明表达内容与标记含义】

## 九、待发明人补充清单
- [ ] 实验数据：____
- [ ] 参数范围：____
- [ ] 附图文件：____
【无补充项则填"无"】
```

## 五要素填写指南

| 要素 | 质量标准 | 常见失真 |
|------|---------|---------|
| 背景与缺陷 | 缺陷必须真实且本发明确实解决 | 编造不存在的缺陷 |
| 技术问题 | 一句话可陈述，与缺陷对应 | 问题泛化（"提高性能"） |
| 技术方案 | 本领域技术人员可再现 | 关键参数缺失、连接关系模糊 |
| 有益效果 | 可追溯到技术特征 | 效果与技术方案脱节 |
| 实施例 | 支撑权利要求全部范围 | 只有一个实施例且无变形 |

## 领域特化要点

- **机械/装置**：整体结构+各部件名称/构造/位置/连接关系+工作原理与过程，必须附结构图
- **电子/软件**：原理框图/电路图/流程图/逻辑关系图+工作过程；软件需绑定硬件载体（"一种____系统/装置"）
- **配方/化学**：成分+配比（范围值）+多个实施例+用途功效；药物类需实验数据
- **方法/工艺**：流程图+分步骤参数+创新点标注

## 禁止事项

1. 禁止虚构实验数据——缺数据列入待补充清单
2. 禁止隐瞒已知缺陷或失败模式
3. 禁止把环境特征（使用场景固有条件）写成发明特征
4. 禁止效果夸大（无法追溯技术特征的"显著提升"）
