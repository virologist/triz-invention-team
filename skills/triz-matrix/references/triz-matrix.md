## 三、矛盾矩阵使用法

1. 将具体矛盾抽象化：改善的具体参数→39参数编号A；恶化的具体参数→编号B
2. 查39×39矩阵交叉单元格，得推荐原理编号（通常2-4个）
3. 逐原理回到具体领域落地为候选方案
4. 注意：矩阵交叉点可能为空（罕见矛盾对），此时改用物理矛盾+分离原理路径

示例：手机性能↑（9速度）导致发热↑（17温度）→ 推荐原理2抽取、28机械系统替代、36相变。

## 四、物理矛盾四大分离原理

| 分离原理 | 适用 | 示例 |
|---------|------|------|
| 时间分离 | 相反要求出现在不同时刻 | 卫星天线发射时收拢/入轨后展开 |
| 空间分离 | 相反要求出现在不同位置 | 保温杯内壁高温/外壁常温（真空层） |
| 条件分离 | 相反要求取决于不同条件 | 光致变色镜片室内透明/室外变色 |
| 整体与部分分离 | 系统层与组件层要求相反 | 锁子甲整体柔韧/单个链环刚硬 |

## 五、ARIZ-85C 九步概要（四五级难题/物理矛盾用）

1. 问题分析：构建问题模型，识别矛盾冲突区
2. 问题模型分析：定义操作区与操作时间，资源清单
3. IFR与物理矛盾定义：明确最终理想结果
4. 动用物质-场资源：标准解法库尝试
5. 应用知识库：效应库、原理库检索
6. 转化与替代问题定义：若未解，重定义问题
7. 分析消除物理矛盾：分离原理应用
8. 利用已得解：构思Substance-Field和具体方案
9. 分析超越问题：检验是否最优解、演化预判

实战中常迭代执行步骤1-7；核心是"把技术矛盾深化为物理矛盾再分离"。

## 六、物-场模型与76标准解速查

三类基本问题：
- 模型不完整（缺场或缺物质）→ 补全（标准解1.1组）
- 有害效应存在 → 加中介物/引入第三物质/改变场（标准解1.2组）
- 效应不足 → 加场强化、加物质改造（标准解2组）

标准解五大类：1类建立/破坏物场（13个）；2类增强物场（23个）；3类向超系统/微观级转移（6个）；4类测量与检测（17个）；5类引入物质与场的策略（17个）。

常用标准解-场景速查（按编号直接查用）：
- 1.1 补全物场（缺S1/S2/F之一）
- 1.2.1 引入S3中介消除有害效应（磁性/热/化学）
- 2.1 引入S3增强有用效应
- 2.2 提高场F强度（可控场）
- 3.1 转移到超系统：将组件A/B转嫁到系统外/相邻系统
- 4.1.1 检测不易测量的变量（引入S2改测易测派生量）
- 5.1 引入廉价S3替代稀缺物质
- 5.2 用空气/水/低成本场替代昂贵场

### 物理矛盾→分离原理快速匹配表

| 物理矛盾场景 | 首选分离 | 备选分离 |
|------------|---------|---------|
| 同一组件不同时刻相反要求 | 时间分离 | 条件分离 |
| 同一空间内相反要求（内/外层） | 空间分离 | 整体与部分分离 |
| 系统层柔性/组件层刚性 | 整体与部分分离 | 空间分离 |
| 环境条件不同则要求不同 | 条件分离 | 时间分离 |
