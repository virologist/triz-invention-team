# 权利要求书与申请文件撰写指南

> 使用者：patent-attorney-writer（权要达）。

## 一、独立权利要求模板

```
1. 一种[发明名称]，其特征在于，包括：
[必要技术特征1]；
[必要技术特征2]；
……
[必要技术特征N]；
所述[特征X]与所述[特征Y]之间[连接/作用关系]，从而实现[核心技术效果]。
```

要点：
- 只写解决技术问题不可缺少的特征——"宽而不超界"
- 前序部分（"一种…"）写与最接近现有技术共有的特征，特征部分写区别特征
- 一个独立权项一个完整技术方案

## 二、从属权利要求模板

```
N. 根据权利要求1所述的[名称]，其特征在于，[附加技术特征限定]。
```

- 引用部分须正确（引用独立或其他从属）
- 择一引用（"根据权利要求1或2"合法；"根据权利要求1-5任一"多项引多项不合法）
- 附加特征按保护价值排序：最想兜底的放最前
- 数量建议3-8项，形成梯度保护伞

## 三、多主题布局

视方案类型平行布局：装置权项+方法权项+系统权项+计算机可读介质权项。软件类必须绑定硬件载体。

## 四、说明书结构

| 章节 | 规范 |
|------|------|
| 技术领域 | ≤3句："本发明涉及____领域，具体涉及一种____。" |
| 背景技术 | 2-4段；描述现状与缺陷，不引用具体专利号；缺陷须与发明内容呼应 |
| 发明内容 | 目的段+方案段（与权项严格一致，逐权项对应）+效果段 |
| 具体实施方式 | 1-3实施例；实施例必须支撑权项全部范围（参数范围给端值+中间值实施例）；结合附图描述 |
| 附图说明 | "图1为____示意图"逐图列出 |
| 摘要 | ≤300字，四句式：领域+核心特征+技术手段+技术效果 |

## 五、禁用词与规范用语（G5 门禁机械校验词表）

**正则可扫清单**（writer 交稿前自扫 + 主理人 G5 复扫，命中即退回，权项与说明书中均适用）：

| 禁用模式 | 正则 | 替代 |
|------|------|------|
| 大约/约/左右/近似/大致 | `(大约\|约\|左右\|近似\|大致)` | 具体数值或明确范围（如"50-80℃"）；权项中"约"仅允许出现在"configure to/配置为"语境外无——一律数值化 |
| 等/之类的/等等 | `(等\|之类的\|等等)` | 封闭式列举或"选自…组成的组" |
| 最好/优选（权项中） | `(最好\|优选)` | 移入说明书或从属权项（权项正文出现即命中） |
| 厚的/薄的（无量化） | `(厚的\|薄的)` | 厚度为____mm |
| 高效/快速（无基准） | `(高效\|快速)` | 效率提升____%（相对____基准） |
| 多个/若干（权项中） | `(若干)` | "至少两个"或具体数量 |
| 大幅/显著提高（无量化） | `(大幅\|显著提高)` | "提高____%"附基准 |

**正则命中后的处置**：①权项正文命中 → 该权项整体退回重写；②说明书命中 → 标注行号退回局部修改；③背景技术中对现有技术的客观描述豁免（但不得进入权项）。

**词表维护**：主理人 G5 门禁扫描即用上表正则；新增禁用词（如审查实践中新出现的模糊表述）由权要达在 failure 记录中提议，经主理人确认后追加到此表。

## 六、附图标记规范

- 非连续编号：元件102、104（预留103增补位）
- 权项中可加括号标记如"[特征X](102)"，但标记不限定保护范围
- 部分海外申请要求附图不含文字——制图时以标号为主

## 七、律师移交包标准内容

1. 核心区别特征清单（独立权项"其特征在于"部分的依据）
2. 高风险点标注（三性裁决中的黄项及修复方式）
3. 建议重点审查项（保护范围取舍点）
4. 实验数据提示（化学/生物类实质审查可能要求补充）
5. 附图待补清单（编号+表达内容）

## 八、质量自检清单

- [ ] 独立权项含全部必要技术特征（细则20.2）
- [ ] 权项以说明书为依据（法26.4）
- [ ] 术语全文一致（同一部件全文一个名称）
- [ ] 无模糊词（大约/左右/等）
- [ ] 从属权项引用关系正确，无多项引多项
- [ ] 实施例覆盖权项全部数值范围
- [ ] 摘要≤300字
- [ ] 所有内容在交底书记载范围内（法33修改边界）
