# 专利撰写工具箱

为技术交底书结构化与申请文件撰写提供**模板 + 机械校验口径**。
主用户：`disclosure-architect`（谭无隐）、`patent-attorney-writer`（权要达）。

**权威源**：`references/disclosure-template.md`（3400 字符）+ `references/claims-writing-guide.md`（4328 字符）。

## 一、何时用 / 何时不用

| 场景 | 用不用 |
|---|---|
| 把技术构思结构化为交底书 | ✅ 用 `disclosure-template.md` |
| 撰写/修改独立权项与从属权项 | ✅ 用 `claims-writing-guide.md` |
| 交稿前扫模糊词、查摘要字数 | ✅ 用 §四禁用词正则 + §三结构表 |
| 组装律师移交包 | ✅ 用 §六 |
| 判定三性 / 引用法条 | ❌ 不用，走 `patent-law` |
| 查新检索与对比文件分级 | ❌ 不用，走 `patent-search-scout` |
| 已经授权后的侵权比对 / 无效宣告 | ❌ 不在本 skill 范围 |

## 二、工作流（两条线，各自有明确输入/输出）

### 线 A：交底书（谭无隐）

**输入**：技术构思 + 领域上下文 + Phase 0 需求卡工程参数
**输出**：交底书（五要素齐备 + 待补充清单）

1. 按模板九节填：名称 / 技术领域 / 背景技术与现有缺陷 / 要解决的技术问题 /
   技术方案（5.1 必要技术特征、5.2 可选技术特征、5.3 工作原理）/ 有益效果 /
   具体实施例 / 附图说明 / 待发明人补充清单
2. **五要素逐节落位**：背景缺陷 → 技术问题 → 技术方案 → 有益效果 → 实施例。
   空缺字段**填"无"或列入待补充清单**，禁止留空或隐匿缺失。
3. `5.1 必要技术特征` 与 `5.2 可选技术特征` 的区分是**下游权项梯度的唯一依据**——
   此处含混会导致独立权项范围失真。区分口径：缺了它技术问题就解决不了 = 必要；
   缺了它方案仍成立但效果变差 = 可选。
4. 输出前跑 G4 缺口扫描：五要素中任一为空 → 不得移交权要达。

### 线 B：申请文件（权要达）

**输入**：交底书 + 三性裁决修复清单
**输出**：权利要求书 + 说明书 + 摘要 + 律师移交包

1. **独立权项**：只写解决技术问题不可缺少的特征——"宽而不超界"。
   前序部分（"一种…"）写与最接近现有技术**共有**的特征，特征部分写**区别**特征。
   一个独立权项 = 一个完整技术方案。
2. **从属权项**：引用部分须正确；**择一引用合法**（"根据权利要求1或2"），
   **多项引多项不合法**（"根据权利要求1-5任一"命中即退回）。
   附加特征按保护价值排序，最想兜底的放最前；数量建议 3-8 项，形成梯度保护伞。
3. **多主题布局**：装置 + 方法 + 系统 + 计算机可读介质平行布局；
   **软件类必须绑定硬件载体**，否则落入法25智力活动规则排除项。
4. **说明书**：按 §三结构表逐节写；发明内容段须**与权项严格一致、逐权项对应**。
5. **摘要**：≤300 字，四句式（领域 + 核心特征 + 技术手段 + 技术效果）。
   🔴 **字数必须机械计量**（`len()`），不得凭感觉自评——failure-006 实证：
   自评"281字"实测 371 字符，G5 门禁被突破。
6. **全文自扫禁用词**（§四正则）后组装律师移交包（§六）。

## 三、说明书结构与硬性指标

| 章节 | 规范 |
|---|---|
| 技术领域 | ≤3 句："本发明涉及____领域，具体涉及一种____。" |
| 背景技术 | 2-4 段；描述现状与缺陷，**不引用具体专利号**；缺陷须与发明内容呼应 |
| 发明内容 | 目的段 + 方案段（与权项严格一致，逐权项对应）+ 效果段 |
| 具体实施方式 | 1-3 实施例；**实施例必须支撑权项全部范围**（参数范围须给端值 + 中间值）；结合附图 |
| 附图说明 | "图1为____示意图"逐图列出 |
| 摘要 | **≤300 字**（细则23），四句式 |

**实施例范围硬规则**：数值范围须有 ≥3 个数据点（两端值 + 中间值），否则不满足法26.3 充分公开。

## 四、禁用词正则词表（G5 门禁机械校验）

交稿前自扫 + 主理人 G5 复扫，**命中即退回**，权项与说明书均适用：

| 禁用模式 | 正则 | 替代写法 |
|---|---|---|
| 大约/约/左右/近似/大致 | `(大约\|约\|左右\|近似\|大致)` | 具体数值或明确范围（如"50-80℃"） |
| 等/之类的/等等 | `(等\|之类的\|等等)` | 封闭式列举或"选自…组成的组" |
| 最好/优选（权项中） | `(最好\|优选)` | 移入说明书或从属权项 |
| 厚的/薄的（无量化） | `(厚的\|薄的)` | 厚度为____mm |
| 高效/快速（无基准） | `(高效\|快速)` | 效率提升____%（相对____基准） |
| 若干（权项中） | `(若干)` | "至少两个"或具体数量 |
| 大幅/显著提高（无量化） | `(大幅\|显著提高)` | "提高____%"附基准 |

**命中处置**：①权项正文命中 → 该权项**整体退回重写**；
②说明书命中 → 标注行号**局部修改**；
③背景技术中对现有技术的客观描述**豁免**（但不得进入权项）。

## 五、检查点（关键决策前停下确认）

| # | 检查点 | 不确认的风险 |
|---|---|---|
| C1 | 独立权项范围划定（宽 vs 窄） | 过宽易被 X/Y 类击毙，过窄无保护价值；取舍须与用户确认 |
| C2 | 交底书存在待补充清单非空时 | 带着缺口撰写会触发法26.3 公开不充分 |
| C3 | 权项中出现必须量化但交底书未给数据的特征 | 要么补数据，要么下调为从属权项——不可凭空填数 |

## 六、边界与异常恢复

| 异常 | 恢复路径 |
|---|---|
| 交底书缺五要素之一 | **退回谭无隐补齐**，禁止凭推理补全未披露内容（法33 超范围） |
| 想写的特征交底书未记载 | **禁止写入**；列入"待补充清单"，由发明人确认后再补（法33 硬边界） |
| 摘要字数接近 300 | 机械计量后重写；**不得以"大概不超"放行** |
| 禁用词在技术领域内是标准术语（如"快速傅里叶变换"） | 标注 `[术语豁免]` 并说明，**不得静默放行** |
| 权项数量超 10 项（费用陡增） | 提示用户附加费（超10项每项加收），由其决定保留哪些 |
| 需要化合物/生物序列等实验数据 | 列入移交包"实验数据提示"，实审可能要求补充 |

## 七、律师移交包标准内容（5 项，缺一不可）

1. 核心区别特征清单（独立权项"其特征在于"部分的依据）
2. 高风险点标注（三性裁决中的黄项及修复方式）
3. 建议重点审查项（保护范围取舍点）
4. 实验数据提示（化学/生物类实审可能要求补充）
5. 附图待补清单（编号 + 表达内容）

## 九、交稿前自检清单（8 项，逐条打勾）

- [ ] 独立权项含全部必要技术特征（细则20.2）
- [ ] 权项以说明书为依据（法26.4）
- [ ] 术语全文一致（同一部件全文一个名称）
- [ ] 无模糊词（§四正则自扫通过）
- [ ] 从属权项引用关系正确，**无多项引多项**
- [ ] 实施例覆盖权项全部数值范围（端值 + 中间值）
- [ ] 摘要 ≤300 字（**机械计量**，非自评）
- [ ] 所有内容在交底书记载范围内（法33 修改边界）
