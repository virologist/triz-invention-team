### 1.1 IFR（理想最终结果）

**IFR描述**：箱体壁面在不增加壁厚的前提下，由壁体自身提供所需热阻；装载空间内不存在非装载用途的实体。

### 1.4 发明等级判定

**判定：3级（实质性改变）**

依据（对照 `references/triz-matrix.md` 第七节判据表）：
1. 问题不是"保温层厚度参数调多少"的单参数优化（1级特征"参数优化"不满足）；
2. 也不是"保温层厚度±少量+局部加强"的本领域少量组合（2级特征"系统改进"部分满足）；
3. 核心矛盾（保温占位 vs 装载容积）在"继续增厚/继续减薄"这条本领域常规轴上是死结，解开它必须把保温功能从"均质附加实体层"改为其他承载形式（结构-功能一体化、真空绝热、相变蓄冷、货物侧保温），解法来源跨到相邻领域 → 命中"实质性改变，解法来源为本领域或相邻领域"；

## 四、物-场模型与76标准解

**模型（有害效应型）**：S1 = 货舱内空气/货物；S2 = 箱体壁体（保温层）；F = 外部热场。
有害效应：外部热场 F 经 S2 传入 S1，S1 得热，S2 越薄该效应越强。
**缺场判定**：绝热功能不足属于"效应不足"与"有害效应"并存。

| 标准解编号 | 名称 | 应用 |
|-----------|------|------|
| **1.2.1** | 引入S3中介消除有害效应 | 在S2内部引入低导热中介层（真空层/惰性气体层/相变层），阻断热场路径，使原保温层实体厚度可降 |
| **2.1** | 引入S3增强有用效应 | 引入高潜热S3（相变材料）吸收漏入热流，把"绝热"转为"蓄冷缓冲" |
| **5.1** | 引入廉价S3替代稀缺物质 | 以低成本可弃型保温被替代部分永久性保温层 |

> 标注：76标准解编号取自 `references/triz-matrix.md` 第六节，与矩阵原理编号属不同层级，分层标注。

## 五、方向推演（逐原理模板）

### D1 · 基于 **#7 嵌套**（来源：T1推荐 与 T2推荐 与 交叉点(22,8)推荐，三处共同命中）

- **核心思想**：把一个物体放入另一个物体内部，一层嵌套一层；让占用空间的结构层彼此共用，消除"层与层之间的无效厚度"。
- **领域启发性问题**：箱体壁体的"外蒙皮／保温芯／内衬板"三层能否合并为嵌套的一体结构，使内衬板不再独立占用装载腔边界厚度？保温层能否嵌进承力结构的内腔而非贴在腔外？
- **跨领域类比案例**：真空保温杯的内外胆嵌套结构；飞机机翼整体油箱把燃油存于承力结构内腔。
- **候选A**：**结构-保温嵌套夹芯壁**。以玻璃钢蒙皮为内外面板，聚氨酯保温芯嵌入两面板之间，取消独立内衬板与骨架所占的腔内侧厚度。装载腔边界即蒙皮内表面。
- **候选B**：**嵌套式可抽插保温内胆**。保温内胆做成可整体抽出的嵌套件，装卸阶段抽出以释放容积，运输阶段推入（与PC3时间分离组合）。

### D2 · 基于 **#18 机械振动**（来源：T1推荐 与 Q2(T3)推荐 与 (26,22)推荐）

- **核心思想**：使物体振动、提高振动频率；振动可改变松散介质的堆积状态。
- **领域启发性问题**：保温层若是松散填充介质，能否通过振动让其在壁腔内的填充空隙率下降，从而在相同热阻下减薄壁厚？壁腔填充过程能否用受控振动替代人工压实？
- **跨领域类比案例**：混凝土浇筑中的振捣密实；粉末冶金中的振动装填。
- **候选A**：**振动密实颗粒保温壁腔**。以气凝胶颗粒或中空微珠为填充介质，装填时施加受控振动使堆积密实度上升、空隙率下降，壁厚在同等热阻下减薄。
- **候选B**：**振动辅助真空排气嵌装**。在真空绝热板热封前的嵌装工序引入振动，排出芯材内残留气体通道。

### D3 · 基于 **#23 反馈**（来源：T1推荐 与 (22,36)推荐）

- **核心思想**：引入反馈，用被控量的实测值反向调节作用强度。
- **领域启发性问题**：箱内温度场是否可以不依赖"均匀厚保温层"维持，而由温度反馈只对热风险区加强绝热？制冷机组的出风口温度能否直接反馈给分区风门而不是反馈给压缩机功率？
- **跨领域类比案例**：冷链运输温度记录仪与回控系统；温室环境的闭环调控。
- **候选A**：**温度反馈分区绝热**。在壁面分区布置温度传感点，反馈信号驱动分区风门开度，只在实测温升区提高冷风流量，其余区域保温层按低限厚度设计（与PC1空间分离组合）。
- **候选B**：**相变节点反馈**。以相变材料的相界面位置作为反馈量，判断蓄冷余量并调节机组启停，降低对壁体热阻的静态要求。

### D4 · 基于 **#13 反向思维**（来源：T2推荐）

- **核心思想**：反置作用方向——不冷却/隔离对象，而冷却/隔离另一侧。
- **领域启发性问题**：保温职责必须在箱体壁体上吗？能否把保温层从"箱体侧"反置到"货物侧"？能否反过来用"移除内部热源"替代"阻挡外部热流入"？
- **跨领域类比案例**：空调服把制冷从"冷却房间"反置为"冷却人体"；手术无菌区反置为"隔离患者"。
- **候选A**：**货物侧保温包装反置**。保温职责下移至货物托盘罩/保温箱套，箱体壁体保温层按低限厚度设计，壁体热阻缺口由货包自身覆盖。
- **候选B**：**热源侧移除**。以箱内蓄冷板承担温度维持，壁体保温层转为"防结露薄层"，冷量来源从壁面绝热转向内部蓄冷。

### D5 · 基于 **#15 动态化**（来源：T2推荐）

- **核心思想**：使物体或其特性在运行中可变化；把不可变结构改为可按工况调节的结构。
- **领域启发性问题**：保温层厚度能否随装载工况改变？空载返程是否可以让保温层处于低占位状态？
- **跨领域类比案例**：可变后掠翼；可充气式隔热帘；汽车可变气门。
- **候选A**：**可抽真空-可充气双层壁**。壁腔在需高绝热时抽真空（热阻上台阶），在装卸与空载返程时充气或泄压以恢复柔性贴合、释放腔体边界厚度。
- **候选B**：**可移出保温嵌板**。立面保温嵌板做成卡扣式可拆件，装载增量需求时按需移出对应区块。

### D6 · 基于 **#16 不足或过量作用**（来源：T2推荐 与 (17,36)推荐）

- **核心思想**：若难以正好达到要求，就做"稍多"或"稍少"的处理，把资源集中到最需要的位置。
- **领域启发性问题**：热流在壁面上的分布是否均匀？角部、门框、机组穿孔周边的热流是否远高于立面中部？把保温材料从立面转移到热桥是否比均匀加厚更省总厚度？
- **跨领域类比案例**：局部淬火只强化受力区；焊接中的局部预热。
- **候选A**：**热桥区过量、立面区不足**。门框、角铝、制冷机组穿管位置按热桥实测加厚并断开热桥，立面中部保温层减薄至低限。总厚度下降同时保持整箱热阻。
- **候选B**：**功能区差异化厚度梯度**。按壁面热流分布设定从门侧到后壁的连续厚度梯度，替代等厚设计。

### D7 · 基于 **#34 抛弃与再生**（来源：T3推荐）

- **核心思想**：物体完成功能后即被抛弃，或功能消耗部分在使用中被再生复原。
- **领域启发性问题**：保温层必须是永久构件吗？能否让"高占位保温件"只在需要时存在，其余时间被抛弃或回收？
- **跨领域类比案例**：运载火箭助推器完成功能后抛弃；一次性医用内衬。
- **候选A**：**可弃型外挂保温被**。永久保温层减薄，高寒线路增挂外置保温被，到站卸载后回收再生（成本受10%上限约束，仅在高寒线路启用）。
- **候选B**：**可再生蓄冷模块**。蓄冷模块在冷库端再生、在途消耗，模块本身不占用装载腔的永久壁厚。

### D8 · 基于 **#39 惰性环境**（来源：T3推荐）

- **核心思想**：以惰性介质替代常规介质，改变介质本身的热物性。
- **领域启发性问题**：壁腔内的介质是空气时导热系数偏高，换介质能否在薄腔内拿到同等热阻？惰性气体与真空相比在成本与泄露风险上如何取舍？
- **跨领域类比案例**：中空玻璃充氩气；白炽灯充惰性气体。
- **候选A**：**薄腔充惰性气体**。以10-15mm密闭腔充氩气替代部分聚氨酯厚度，利用气体低导热率。
- **候选B**：**真空腔＋吸气剂**。薄腔抽取真空并置吸气剂维持真空度，等效热阻高于同厚度聚氨酯。

### D9 · 基于 **#40 复合材料**（来源：T3推荐）

- **核心思想**：用复合材料替代单一材料，使多种性能在同一层内实现。
- **领域启发性问题**：承力与绝热能否在同一层内同时实现，从而不叠加两层厚度？能否用各向异性材料让强度沿受力方向、绝热沿法向？
- **跨领域类比案例**：碳纤维增强层合板；泡沫夹芯结构件。
- **候选A**：**结构-绝热一体化夹芯板**。玻璃钢面板＋高强泡沫芯＋纤维增强肋，承力由面板与肋承担，绝热由芯承担，壁体总厚低于"独立骨架＋独立保温层"方案。
- **候选B**：**各向异性导热壁**。面内高导热（匀化局部热点）＋法向低导热（阻热流），用同一层材料同时实现均温与绝热。

### D10 · 基于 **#35 参数变化**（来源：(22,39) 与 (39,22) 与 (7,30) 推荐）

- **核心思想**：改变物体的物理状态、浓度、密度、柔性、温度各参数。
- **领域启发性问题**：保温材料的导热系数能否随温度变化，使其在温升风险时自动升高热阻？能否用相变把"绝热"改为"恒温缓冲"？
- **跨领域类比案例**：温敏变色材料；相变储能墙体。
- **候选A**：**相变材料复合保温层**。在保温层内嵌相变微胶囊，漏入热流先被潜热吸收，允许降低稳态热阻要求进而减薄。
- **候选B**：**温敏导热层**。在热桥处设置低温高阻、高温低阻的温敏层，把热流导向可被蓄冷吸收的路径。

1. **约束过滤**：改造成本上限 = 单箱制造成本10%。真空绝热板（D8-B/D14）、可抽真空双层壁（D5-A）、自修复微胶囊（D19）为高成本项，单箱改造成本进入同一量级，与10%上限存在冲突，优先级下调。
2. **失效容忍度过滤**：整箱失冷不可接受、局部保温性能下降可接受。因此"壁体整体减薄换容积"（T2单点）不可接受；必须保留整箱热阻下限。
3. **首选组合（互补，非并列）**：**D1-A（#7嵌套）+ D6-A（#16不足或过量作用）+ D3-A（#23反馈）**。
   - D1-A 消除"内衬板＋骨架＋保温层"的层间无效厚度，直接回收装载容积；
   - D6-A 用热桥区过量、立面区不足的差异化厚度，替代等厚设计，在整箱热阻不降前提下降低平均壁厚；
   - D3-A 用温度反馈把"均匀静态热阻"改为"按实测温升分区调节"，允许静态热阻设计点下移。
   - 三者分别落在**结构嵌套层、厚度分布层、控制层**，作用维度不重叠，可叠加。
4. **次选**：**D10-A（#35参数变化）** 作为热阻缺口的补足手段，在成本允许时与首选组合叠加。
5. **明确不推荐单独使用**：D4-A（保温职责整体反置到货物侧）虽实现难度低，但把保温可靠性转移到货包一致性与装卸管理上，与"整箱失冷不可接受"存在张力，仅可作为局部补充。

## 七、选定方案技术特征三件套（素材，非申请文件）

### 7.1 核心技术特征（独立权项素材）
—— 对应首选组合 D1-A ＋ D6-A
1. 一种冷链运输箱体壁体结构，包含外蒙皮与内蒙皮，二者之间形成密闭芯层腔；保温芯材嵌装于该芯层腔内，**箱体内表面由内蒙皮直接构成**，不设置独立内衬板。
2. 所述保温芯材在壁面不同区域具有**非等厚度分布**：热桥区域芯层厚度大于立面中部区域芯层厚度，且热桥区域设置断热桥结构。
3. 所述壁体在装载腔边界处的厚度由外蒙皮、芯材、内蒙皮三层嵌套构成，层间无独立骨架占位。

### 7.2 可选技术特征（从属权项素材）
—— 对应 D3-A、D10-A、D2-A、D16、D13
1. 所述内蒙皮外表面布置温度传感点，传感点输出连接分区风门执行机构（#23 反馈）。
2. 所述保温芯材内嵌相变微胶囊，相变温度区间与箱内目标温区重合（#35 参数变化）。
3. 所述芯层腔填充颗粒状绝热介质，填充工序施加受控振动（#18 机械振动）。
4. 箱体门框设置充气密封条，闭合状态下内部气压高于外部气压（#29 气动与液压）。
5. 箱体门口设置对接门斗，装卸状态下与外部月台密封对接（#21 减少有害作用的时间）。

### 7.3 技术效果描述（创造性论证素材）
1. 装载容积：取消独立内衬板与独立骨架所占腔内侧厚度，装载腔边界内推至内蒙皮内表面，在箱体外廓不变的前提下释放装载容积。
2. 保温性能：壁面厚度按热流分布差异化分配，热桥区热流被重点阻断，立面区厚度下降与该处热流下降相匹配，整箱热损失不因平均厚度下降而上升。
3. 温度稳定性：温度反馈分区调节替代静态均匀热阻，箱内温度波动由控制回路吸收，降低壁体静态热阻的设计裕度需求。
4. 成本一致性：加工工序由"多层独立件装配"改为"芯层嵌装＋面板合模"，与单箱制造成本10%上限相容。
5. 维护一致性：年检维护对象为蒙皮外表面与密封件，芯层腔密闭不外露，维护频次与年检节奏相容。
