# 发明专利技术交底书

## 一、发明名称

一种粪沟刮粪板

（备用名称：一种带免工具自锁可换刃条的粪沟刮粪板）

## 二、技术领域

本发明属于畜牧养殖清粪设备技术领域，具体涉及猪舍粪沟用刮粪板的可更换抗磨结构与锁止结构。

## 三、背景技术与现有缺陷

（按 disclosure-template 要求，本节只描述技术现状，不引用具体专利号；专利号见附录D 与基线节。）

1. **现有技术方案 A（刮板级可拆连接）**：在牵引链与刮粪板之间设连接座或连接柱，刮粪板以插接块与插接槽、限位块与限位槽配合的方式装配于其上，并以弹簧顶推或弹性力臂复位的方式保持连接。磨损后可整体更换刮粪板或更换刮板级插接件。
2. **现有技术方案 B（刮板本体上直接嵌设耐磨条）**：在刮板本体下表面设开口向下的卡槽，耐磨刮条半嵌入卡设；更换耐磨条时不拆下刮板本体。耐磨条多采用超高分子量聚乙烯。
3. **现有技术方案 C（耐磨条卡板卡合 + 工具紧固）**：以安装侧板与连接板为过渡，耐磨条连接卡板与连接槽卡合，再以固定螺栓将卡合状态固定。
4. **现有技术方案 D（异色判磨耗）**：以两件颜色相异的零件（支撑座与刮除单元）相互对照，据顶缘至结合线的距离判断是否更换。

**现有技术共同存在的缺陷：**

- **缺陷1**：可拆界面停留在刮板级——每次更换均需拆装刮板本体或刮板级插接件，被换下的零件中包含大量未磨损的承载结构，换件成本与拆装工时未被压缩到磨损部位本身（技术后果：换件重量与拆装步骤数高于必要水平）。
- **缺陷2**：锁止依赖弹性储能件（弹簧、弹性力臂）或人工外力加独立紧固件（固定螺栓、弹性开口销）；弹性件在粪沟高湿、含氨与粪污固结工况下存在应力松弛与卡滞，紧固件需工具操作且拆装后存在丢失与漏装风险（技术后果：锁止可靠性随时间下降，维护动作依赖工具）。
- **缺陷3**：卡合方向与固定方向同向，解脱须以工具解除紧固件；卡合面位于整体件上，磨损直接作用于承载件接口面（技术后果：接口面一旦磨损，需更高级别的零件更换）。
- **缺陷4**：磨耗判断需依靠第二件对照件或人工量测，判断动作未能前置到固定巡检时点（技术后果：判磨动作与巡检节拍不同步）。

## 四、要解决的技术问题

本发明针对粪沟刮粪板「可拆界面层次过高、锁止依赖弹性件或独立紧固件、卡合面直接受损于承载件」的问题，提供一种粪沟刮粪板，以解决现有技术中**磨损仅发生于小体积可换件上的目标与承载本体免换、以及锁止不依赖独立紧固件与工具且解脱方向可辨识这三者无法在同一装配体上同时实现**的技术问题。

（一句话陈述：把可拆界面下沉一级、把锁止能量来源由弹性件或人工外力改为刮粪行进力，从而在无独立紧固件的前提下同时实现锁止可靠与免工具解脱。）

## 五、技术方案

### 5.1 必要技术特征（独立权利要求素材）

> 兑现 **M1/M2/M3/M4**。四条特征构成同一装配体的单一技术方案，特征间以装配关系与力传递关系相连；必要特征集合内不含 N4、N5、N6（兑现 **K5**）。

**F1 · 三级体结构**
刮粪板包括**承载本体**、**中介座**与**耐磨刃条**；所述承载本体与牵引链连接；所述中介座与所述承载本体**固定连接**且为刮粪板使用期内**不参与拆装作业**的保留件；所述耐磨刃条与所述中介座构成刮粪板上的**唯一可拆界面**。

- **F1(a) 封闭式固定连接列举**（兑现 M2(a)）：所述中介座与所述承载本体的固定连接方式为**焊接、过盈配合、螺纹紧固中的一种**（封闭式列举，不含兜底表述）。
- **F1(b) 运行期功能限定**（兑现 M2(b)）：所述中介座在刮粪板的使用期内不参与拆装作业；刃条的更换动作与所述承载本体、所述中介座均不发生分离。
- **相对性术语替换**（兑现 S4，可核查表述）：以「解脱动作不含工具操作」替代「快换」；以「全部刃条位共用同一接口几何」替代「标准化」（后者仅作为可选特征 F6 出现）。

**F2 · 行进力分量驱动的楔面自锁几何**
所述耐磨刃条与所述中介座之间设**楔形锁止面**；刮粪行进方向的分量把所述刃条压向所述中介座的卡合面，形成摩擦自锁。

- **F2(a) 楔角与摩擦角的大小关系**（兑现 M3）：所述楔形锁止面的楔角 β **小于等于** 所述刃条与所述中介座界面在粪沟工况下的摩擦角 φ，即 β ≤ arctan(μ)，μ 为该界面的摩擦系数。
- **F2(b) 推入方向限定**（兑现 M3）：所述刃条沿**垂直于刮粪行进方向**的推入轨迹插入所述中介座的导轨卡合面，并于推入行程末端进入自锁区。
- **表述形式要求**（兑现 M3 后半）：F2 不得以效果性表述（例如「行进力使其自动锁紧」）作为唯一限定，必须以 F2(a) 的关系式与 F2(b) 的方向限定固化。

**F3 · 与 F2 绑定的免工具解脱复合限定**
所述楔形锁止面的设置方向使所述刃条的**解脱方向与刮粪行进方向相反**；所述刃条与所述中介座的界面**不含螺栓与开口销**，沿所述解脱方向反向抽拉即解脱。

- **绑定要求**（兑现 M1）：「解脱动作不含工具操作」这一要素**不与「方向相反」分离成句**，两者在同一限定中绑定；F3 不单独作为独立区别特征出现。

**F4 · 回程防解除限定**（兑现 M4，二者取其一）
**（F4-1）单向刮粪行程**：所述刮粪板配置于单向刮粪行程的设备；或
**（F4-2）防倒抽限位结构**：所述中介座上设与所述楔形锁止面配合的**止退台阶或挡销**，使回程反向力不解除 F2 的自锁状态。

**F1—F4 之间的技术关系**：F1 提供可拆界面的层次（磨损止于刃条，承载本体与中介座为保留件）；F2 提供界面内的锁止力来源（行进力分量，而非弹性件或人工外力）；F3 提供与 F2 互为逆过程、方向相反的解脱路径，使「锁止—解脱」由同一楔面在时间上分离与在条件上分离，因此无需 F1 界面内的任何独立紧固件；F4 封闭回程与固结工况下 F2 被解除的路径。四者缺一，则「无独立紧固件 + 免工具 + 锁止可靠」不能同时成立。

### 5.3 工作原理与过程

**（1）装配阶段**：中介座以 F1(a) 的固定连接方式之一固接于承载本体，形成运行期保留件；耐磨刃条沿垂直于刮粪行进方向的推入轨迹（F2(b)）插入中介座导轨卡合面，于行程末端进入自锁区；界面内不安装螺栓、不安装开口销（F3）。

**（2）刮粪行进阶段**：牵引链带动承载本体与中介座沿刮粪方向行进；沟内物料对刃条的反作用力中，沿刮粪方向的分量通过楔形锁止面把刃条压向卡合面。当楔角 β 满足 β ≤ arctan(μ)（F2(a)）时，该压紧力自身产生的摩擦力大于使刃条反向脱出所需的分量，界面进入自锁状态，锁止不由任何弹性件储能维持。

**（3）回程阶段**：按 F4-1，设备为单向刮粪行程；或按 F4-2，回程反向力由止退台阶或挡销承担，楔面自锁不被解除。

**（4）维护阶段**：维护人员以手反向抽拉刃条，楔面脱离自锁区后刃条即沿导轨推出，解脱动作不含工具操作；解脱方向与刮粪行进方向相反（F3），该方向关系构成现场可辨识的操作提示。更换后仅刃条被替换，承载本体与中介座保持不变。

**（5）磨耗判断阶段**：按 F5，刃条工作层磨透至指示层后显色，于季检时点以目视判断；按 F5-a，当显色带宽达到 d/t 对应阈值时更换。

**（6）楔角核算过程（兑现 M5(a)，说明书实施方式素材）**：
1. 确定界面配对副：刃条材料与中介座材料（材料组合见可选特征 F7 与实施例）。
2. 确定界面摩擦系数 μ 的**实测取值**。该取值须以配对副在粪沟实际工况下的实测结果确定；本交底书未取得该实测值，已在缺口清单第 2 项登记，本处不以假设值替代。
3. 由自锁条件求得楔角上界：β_max = arctan(μ)。
4. 在 β ≤ β_max 内选取楔角设计值，并预留安全裕度（取值点位见实施例）。
5. 按 F4-2 校核回程反力下止退台阶或挡销的承载能力。
6. **核算禁止项**：不得仅以经验值填写 μ 而省略第 2 步实测；不得以 β 大于 arctan(μ) 的取值主张自锁。

## 六、有益效果

> 量化说明：本交底书未取得任何实测数据，故效果 1 至效果 3 以**定性效果 + 机理**陈述，效果 4 给出**可量测的指标口径**而不给数值。全部量化数值均登记于缺口清单第 1 项，待发明人补测后回填；本处不填任何效果数值（禁止虚构实验数据）。

1. **换件范围收窄（定性 + 机理）**：可拆界面下沉至刃条级（F1），使每次更换被替换的零件仅为耐磨刃条，承载本体与中介座为保留件。机理在于磨损的有害效应被限制在体量最小的零件上，故换件重量与拆装步骤数由「刮板级」降至「刃条级」。
2. **锁止不再依赖弹性件与紧固件（定性 + 机理）**：锁止力来源为刮粪行进力分量（F2），界面不含螺栓与开口销（F3）。机理在于锁止能量由运行过程自身提供，不存在弹性件在粪沟高湿与含氨工况下的应力松弛与卡滞问题，也不存在紧固件拆装后的丢失与漏装问题。
3. **解脱动作不含工具且方向可辨识（定性 + 机理）**：解脱方向与刮粪行进方向相反（F3）。机理在于楔面自锁的解除必须以与自锁压紧方向相反的力实现，故解脱方向在结构上被单向锁定，维护人员无需在沟内辨识零件朝向即可完成操作。
4. **可量测的指标口径（不给数值）**：效果 1 以后续实测的「单次换件重量（kg）」「单次换件步骤数（项）」计量；效果 2 以后续实测的「维护动作中工具使用次数（次/次换件）」与「连续换件周期内锁止失效次数（次/周期）」计量；效果 3 以后续实测的「单次换件用时（min）」计量。上述指标的实测值登记为缺口清单第 1 项。
5. **磨损判断与巡检节拍同步（定性 + 机理，对应 F5/F5-a）**：指示层显色使判断依据由外部对照件转为刃条自身厚度方向的构造，判磨动作可安排在季检时点完成（对应 A02 采纳的预先作用原理路径）。

## 七、具体实施例

> **数据性质声明**：以下全部结构参数与工艺参数为**设计取值**，用于界定可实施的取值点位与范围；**均非实验数据**。每个数值范围按「端值×2 + 中间值×1」配置点位（必要时增列偏离点位验证边界），摩擦系数与全部效果数值均登记为待补测缺口。实施例覆盖两档猪舍规模。

### 实施例1（最优方案 · 中小规模单列式猪舍）

- **应用场景**：单列式育肥猪舍，粪沟为明沟，牵引链单向循环刮粪。
- **结构**：承载本体（钢板焊接件）—中介座（与承载本体**焊接**固定，F1(a) 第一种）—耐磨刃条（超高分子量聚乙烯，与承载本体材料及热处理均不同，F7）。界面内无螺栓、无开口销。
- **点位（一）楔角 β**（F2(a)，自锁条件 β ≤ arctan(μ)）：设计点位 **β = 6° / 10° / 14°**（端值×2 + 中间值×1）。
  - 对应各点位所需的最小界面摩擦系数 μ_min = tan β 的**反算阈值**为 **0.105 / 0.176 / 0.249**（该三值为纯几何反算，非实测数据）。μ 的实测值待补测（缺口第 2 项）；若实测 μ 低于某点位的 μ_min，则该点位不满足自锁条件，须下调 β。
- **点位（二）刃条厚度 t**（F8）：**t = 8 mm / 12 mm / 16 mm**，选定 t = 12 mm。
- **点位（三）指示层深度 d**（F5-a，d ≤ 0.5t）：**d = 2 mm / 4 mm / 6 mm**，选定 d = 4 mm。
- **点位（四）牵引链速**：**2.0 / 3.0 / 4.0 m/min**，选定 3.0 m/min。
- **几何**：粪沟宽 400 mm，栏长 30 m，刮板宽 380 mm。
- **回程处置**：按 F4-1（单向刮粪行程）配置。
- **操作步骤**：停机→反向抽拉刃条（不含工具操作）→目视指示层是否显色并量测显色带宽度→推入新刃条至行程末端自锁→恢复运行。
- **结果数据**：本交底书未取得实测结果，登记为缺口第 1 项；不得填写数值。

### 实施例2（变形方案 · 大规模双列式猪舍）

- **应用场景**：双列式母猪舍，粪沟为深沟（沟深加大），牵引链单向循环刮粪，单板载荷高于实施例1。
- **结构差异**：中介座与承载本体的固定连接方式改为**过盈配合**（F1(a) 第二种，作为连接方式的变形验证）；介质环境更差的沟段按 F9 设防污遮蔽面。
- **点位**：楔角 **β = 6°**（取实施例1 三点位中的最小端值——大载荷工况下须在 β ≤ arctan(μ) 内预留更大安全裕度）；刃条厚度 **t = 16 mm**（取大端值）；指示层深度 **d = 6 mm**；牵引链速 3.0 m/min。
- **几何**：粪沟宽 600 mm，栏长 80 m，刮板宽 580 mm。
- **回程处置**：按 F4-2（**止退台阶**）配置，以覆盖回程反向力大于实施例1 的工况。
- **可选特征落实**：F6（同一中介座接口几何适配 t = 16 mm 与 t = 12 mm 两种刃条规格，对应 S1 的两种规格实施例）。
- **结果数据**：同上，登记为缺口第 1 项。

### 实施例3（变形方案 · 边界点位与替代结构验证）

- **小截面边界点位**：粪沟宽 300 mm，栏长 20 m，刃条厚度 **t = 8 mm**（小端值），楔角 **β = 14°**（大端值）。该组合在 μ 实测值不低于 0.249 时满足自锁条件；若实测低于该阈值，则须下调 β 或改用 F4-2。
- **替代结构一**：F4-2 的防倒抽限位以**挡销**替代实施例2 的止退台阶（验证 F4-2 的替代实施方式）。
- **替代结构二**：F1(a) 的固定连接方式以**螺纹紧固**实现（第三种），用于中介座需在出厂前调整位置的实施场合。
- **偏离点位（用于验证边界失效）**：β 取大于 arctan(μ) 的取值时自锁不成立，界面在行进力作用下不产生净压紧，本偏离点位仅作为边界对照记录，不落入保护范围。
- **结果数据**：同上，登记为缺口第 1 项。

## 附录A · N2 支撑强度替代方案评估（兑现 K2）

### A.1 问题重述

A04 的三步法自身得出两项否定性结论：D1（对应 F1）存在同领域与相邻领域的技术启示、非显而易见性不成立；D2（对应 F2）的功能与效果已被 A01 §4.1 的两条 X 级文献预期。故独立权项的创造性实际由「以运行力分量替代弹性储能件与人工外力」这一手段差异单点支撑（A05 §二 2.2）。该单点支撑同时承担两重风险：**未经定向检索的负向假设**，以及**位于公知常识射程内**。

### A.2 M3 与 A-1 的互斥及取舍（显式回答）

**互斥的本来形态**：M3 拟以「楔角 ≤ 界面摩擦角」固化 F2；A-1 指出该关系式正是斜面自锁的公知条件（自增力制动器、楔块式单向离合器、锥面自锁刀柄）。若 A-1 成立，则 M3 只是把公知条件写入权项；若 A-1 不成立，则无需以公知条件固化。两者不能同时为真。

**取舍结论（三项）**：

1. **保留 M3 的形式，但改变其功能定位**。F2(a) 的 β ≤ arctan(μ) 关系式**继续保留为结构限定**，理由是：法26.4 要求保护范围清楚，若不以结构关系限定，F2 只能以效果性表述（「行进力使其自动锁紧」）主张，反而落入 A04 攻击#7 的清楚性缺陷。故 M3 的作用由「提供创造性支点」**降级为「提供清楚性与可实施性的结构表述」**。
2. **创造性支点上移**。独立权项的创造性不再由 F2(a) 单独承担，改由**组合支点**承担：
   - **主支点候选**：F4（F4-1 单向刮粪行程 或 F4-2 防倒抽限位结构）——该限定在 A04 的 M7a 与 K1 的 M7b 两式**均未被检索覆盖**，构成未经检索的独立构造限定；其与 F2 的组合（楔面自锁 + 回程防解除）在当前 X 级文献中无对应记载。
   - **辅支点候选**：F1(a) 封闭式固定连接列举的**具体方式**与 F1(b) 运行期不参与拆装的功能限定所构成的「层次固定」+ F2(b) 的推入方向限定，三者组合形成的装配体整体构造。
3. **明示风险**：主支点候选同样属于「未经定向检索」的状态（M7b 未执行），故本取舍结论为**条件性结论**，其成立以 M7b 回阴性为前置（对应 K6）。
