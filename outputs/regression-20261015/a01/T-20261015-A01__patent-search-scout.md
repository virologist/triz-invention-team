### 6.2 核心区别点清单（直接供权要达撰写独立权项"其特征在于"部分）

以下按"相对未被单篇文献公开"排序，第1项为最可能支撑创造性的特征，第3—6项适宜作从属特征：

1. **三级可分离构造 + 中介层运行期固定**：所述耐磨刃条与所述安装槽之间设有中介座，所述中介座在运行期相对于所述刮板承载本体位置固定且不参与拆装作业，所述耐磨刃条相对于所述中介座可拆装。→ 三轮检索未检出等同构造；相邻领域仅有"连接座整体可更换"（CN119734955A）与"过渡哑铃 + 安装座可拆卸"（CN102502176A），均非本构造。
2. **双向自由度约束 + 免工具单手解脱的组合**：所述限位结构在锁止状态下同时约束所述耐磨刃条沿刮粪方向与垂直于刮粪方向的相对运动，且其解脱动作由手动完成、不依赖工具。→ 现有 X 类文献只约束插拔方向（CN223231803U、CN214126439U），或依赖螺栓/开口销（CN118255103A、CN108094223B），"双向约束 + 免工具单手解脱"的组合未在单篇文献中检出。
3. **刃条横截面沿厚度方向上下对称**，可在同一安装槽内翻转180°安装。→ 本领域未检出；跨领域已公开（CN205351353U、CN207981556U），单独主张创造性风险高，宜作从属特征。
4. **多层薄片叠合 + 相邻薄片间可剥离弱结合层**的分层剥离再生构造。→ 三轮检索未检出，须外部核验后使用。
5. **硬度梯度复合刃条**：与粪沟接触的表层硬度高于与安装槽配合的根部硬度。→ 未检出专门文献，须外部核验后使用。
